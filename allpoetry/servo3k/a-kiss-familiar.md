title: "a kiss familiar"

a kiss so familiar
a kiss so soft
eyes so blue
a glassy stare
hair so black
(love to run my fingers through it)
hands so secure
a hold so close
so comforting
a voice so calm
a voice so loving
will i ever find these things again?
