title: "Set it Off"
writer: "Behind the Smile"

Set it off
Let it be

Change it all
Cage the enemy

Set it off
Let it be

Prepare the future
Repare the past

Set it off
Let it be

Save a life
Repave the cracks

Set it off
Let it be

Change your destiny
Rearrange your certinity

Set it off
Let it be

Give up the fight 
Live in sight 

Set it off 
Let it be

Hope for the best
Cope with the rest

Set it off let it be
