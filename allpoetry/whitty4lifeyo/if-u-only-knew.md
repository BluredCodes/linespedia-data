if only u knew, that when u smile my heart sings
if only u knew, that when i picture u i picture the universe in my hand
if only u knew, that when i think about u i lose control
if only u knew, what its like being me
if only u knew

if only u knew, that my happiness only comes from hearing ur voice
if only u knew, that my joy comes from the sweetest things u say
if only u knew, that by the way u are keeps my engine flowing
if only u knew, what my heart tells me every night
if only u knew, what i feel
if only u knew

if only u knew, that u mean so much 2 me
if only u knew, what passes by my mind
if only u knew, what goes on inside me
if only u knew, that i still care
if only u knew, that i still love u
if only u knew, that i will be there
if only u knew, that this i say is true
if only u knew, how i felt
if only u knew

if only u knew, how much i miss u
if only u knew, how u make me feel
if only u knew, what im saying is true 
if only u knew, that my words mean that much to u
if only u knew, ill always be there for u no matter what
if only u knew, what pain was 
if only u knew, that if it comes down to it ill be the first to be there to help u
if only u knew, what u missed
if only u knew

this poem was designed to just be a turning point of my writing
something or someone inspired me to write these poems.
but now i only write of my self 
poetry writing has been fun but i might just stop writing cuz i think
im hurting people inside
i think mah words are hurting certain individuals
ill rest awhile......~*sean*~ A.K.A. whitty biohazard
