one more year
one more day
it makes no difference
always the same

if i am with you 
if i am not
i am still empty
still alone in the dark

one more kiss
one more time
it wouldn't make a difference
if i wern't alive

if i let you
if i did not
you wouldn't care
you would just go onto my ass hole ex
