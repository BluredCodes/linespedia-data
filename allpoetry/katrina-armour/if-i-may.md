If I didn't wear this skin
If I could just hold it in
If I could ignore my debts
If I hadn't made them pets...

If I may...if I may...
I would like to-

If I could keep you in a jar
If I didn't have these scars
If I hadn't fucked this up
If I hadn't been so stuck...

If I may...if I may...
I would like to-

If you could just fade away
If you had no need to stay
If I held you in my heart
If I tore myself apart...

If I may...if I may...
I would like to-

If I took a crayon and scrawled
bold upon my bedroom wall
I'll love you 'til my world falls down...
if I may.

If I gave my heart to you
and did all that I wanted to
would you still let me speak my mind?
I would like to.

If I may...if I may...
I would just like to
