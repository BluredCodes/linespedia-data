somewhere
there
is 
a
meaning
for
all
of 
this

If you only knew
If you only knew

Someday
we
won't
need
to
insist

If you only knew
If you only knew

So take it
hide it deep inside
remember
It will be clear
in time

If you only knew
If you only knew

Can't tell you
you'd wonder
why I feel this way

You'd only
reconsider
couldn't bear
to hear you say

Its not you
Its not you
Its not you
Its me

If you only knew
