A poet-tree garden is set in neat lines
well-tended, and nurtured, it's trimmed many times
it grows when it's cared for...it's bent when it's not
most poet-tree gardens they offer a lot ....
~
A poet's tree is Poplar if it's often read
A poet's tree would be Ash if the work is too weak
A poet's tree is a stump when the writer is dead
a poet's tree is Maple if the words all flow sweet
a poet's tree is Cherry if it was your first
a poet's tree is Plum if the lines are all straight
"     "     " is a weeping Willow if the subject is sad
                                by-artis and Iluvpoetry
              would be Locust if it bugged anyone 
              would be Hemlock if it poisoned the soul
              would be Oak if it's substance was strong        

a poet's tree would be Balsa if the verse was quite light
              would be Rubber if it bounces along
              is a Sequoia with high aspirations
              could be Cactus if it prickles one's conscious
              could be Palms offering one's latest rhyme
              could be Petrified if it frightens or threats
"      "    " is a Beech, with the sun, surf and sea
a poets tree  is a Laurel every word forms a wreath
              that brings peace to the reader 
              with each thought it bequeaths
              is a Bottletree pour out your soul
              could be Camphor it comforts and soothes
a poet's tree can be Pine if it's full of yearning
                                        by-Bonnie Blue
              is a Cork tree pop it free, loose your heart
              is a Flame tree burning bright with your passion
              is a Lemon oftentimes bittersweet
              is a Cypress if presses print it you sigh
              is a Maidenhair tree..soft strokes of genius
              brushed to a fine sheen
a poet's tree is an Apple freshly plucked...juicy ripe
              an Octupus tree eight lines that reach out 
              and grab you
              can be Pepper spicy...red hot in flavour
              can be a Punk tree radical twisted growth
a poet's tree can be Dentistry filled in or polished
"     "     " is Optometry it brings clearer vision
              Geometry patterned and metered
              is Chemistry experimental creations
A poet's tree could be gum if it's words stick with you 
                                        by-Mysty saimt
~
a poet's tree is a bigot where your hang ups are strung
a poet's tree is an en-tree to a mystical world
a poet's tree is from gen-tree if the poet is male
a poet's tree is a sen-tree if it holds all your thoughts
locked away on a site, where folks visit a lot
a poet's tree is element-tree when your small, and you write
a poet's tree is a Beech full of cinammon leaves 
it's a bake shop where words rise warm and fresh between sheaves.-by-gozling
a poet's tree like an Oak bursts from one tiny seed
so majestic and strong...as it answers each need..by-gwion
a poet's tree is a Yum-Yum cause it sweetens the senses.
by-maureen
a poet's tree is the ivy when it won't let you go...-by-Hide
a poet's tree is a Christmas tree, with all the gifts it bears
whether rapped or given with much love, it's what most folks love to share ...by-hide and artis
a poet's tree is an olive tree, each olive branch extends 
hope for peace and love's return in Palestine and Jerusalem
-by-Bonnie Blue and Artis
a poet's tree is a mimosa ..sensitive to the touch of any
it shrinks, and folds, then boldly regrows, to share how it's moved by many -Bonnie Blue and Artis
~
if you too have a poet's tree you'd like to add
put it into my comments whether it's good or bad
from each tiny thought planted in a site such as this
will grow rare poet trees that will fill us with bliss
play around with the word, add in your favorite tree
and we'll see just how big this old garden can be
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~Artisthis is meant to be an interactive piece...there are any number of words that end in a tree sound or have tree in them or are the names of trees..jump in and I'll give you credit for each line
