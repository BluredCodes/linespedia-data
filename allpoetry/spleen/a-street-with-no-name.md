I'm always driving forever flying the view is blinding
But where am I going and what should I be finding
When will I know where the hell it is that I'm supposed to go
Passing faces confused in a blur, my pace is so very slow it's painful

And I always find myself driving down a street with no name
No matter which way i take it always ends up the same
And it's always the same driving on this street with no name

So many different directions all leading to this dark murky self reflection
To turn right  is to turn left there is only one direction 
And in the end they all lead to this there's no exception
No exceptions, there's no direction, the lack of truth please don't mention

chorus

And I'm always driving down this street with no name
So many paths, in the end they're all the same
All the same
It's all the same
It's all the same
Everything's always the same on this street with no name
